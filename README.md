# 고려대학교 정치외교학과 대학원 프로그램 홈페이지

빌드 과정이 없는 정적 사이트입니다. `index.html`을 브라우저로 열면 바로 보입니다.

## 행사 추가·수정
`data/events.js` 한 파일만 고치면 모든 페이지(분류별 목록, 첫 화면의 강연 영상·다가오는 행사·최근 행사)가 바뀝니다.
파일 맨 위에 항목 설명이 있습니다. 비슷한 행사를 복사해서 값을 바꾸세요.

- 영상 공개: 해당 행사에 `video: "YouTube영상ID"` 를 넣습니다.
- 포스터 이미지: `assets/img/` 에 넣고 `poster: "assets/img/파일명.jpg"` 로 연결합니다 (가로 1400px 이하 권장).

## 올리지 않는 것
참가자 명단, 평가표, 신분증·통장 사본 등 행정서류, 연사 슬라이드(비공개 방침), 동의받지 않은 학생 포스터 전문.

## GitHub Pages 배포
1. GitHub Organization에 저장소를 만들고 이 폴더 내용을 올립니다.
2. 저장소 Settings → Pages → Branch `main` / `/ (root)` 선택.
